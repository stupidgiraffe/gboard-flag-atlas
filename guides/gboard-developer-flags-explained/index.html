Gboard Developer Flags Explained: What Is Actually Hidden?

Understand Gboard's internal experiment flags, which identifiers are real switches, and why turning one on often changes nothing.

What you should know

A string recovered from an APK is evidence that an identifier exists, not proof that you can toggle a working feature.

Evidence standard: these are real catalog identifiers, but their effects can be inferred, version-specific, or gated. Check the confidence and APK notes before changing settings.

What counts as a flag

Gboard contains experiment gates, stored preferences, numeric thresholds, model selectors, diagnostics and version-specific settings. The Atlas catalogs identifiers found in a GboardWu 18.5.4 snapshot; it does not claim every string is a user-editable boolean. An apparently descriptive name can still point to a dormant experiment, an internal counter, or a parameter whose useful values are undocumented.

Read the identifier and the evidence separately

Start with the exact identifier, then compare its confidence label and notes. Name-derived means we can parse the words but have not traced the behavior. Interpreted means the context is stronger. Code-referenced means implementation evidence exists; it is still not a promise that Google has enabled the feature for your account, language or device.

A safe way to explore

Prefer ordinary Gboard settings first. On a compatible patched build, record the current flag value and Gboard version, change one parameter at a time, and reproduce the specific behavior in the same app and language. Undo changes that cause startup problems or unreliable input. Treat root-only tools as inspection instruments, not as evidence that the option is effective.

Frequently asked questions

Are these official user-facing settings?

Usually not. The Atlas includes internal identifiers and experimental configuration, not a Google-approved list of user options.

Does finding a flag mean it works?

No. Feature eligibility, server configuration and compiled code paths can all limit what happens.
